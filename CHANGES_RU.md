# WaveChess 3.0 — результаты и границы

Горизонт увеличен с 16 до 48 полуходов по умолчанию, предел — с 128 до 256. Продолжения больше не обрываются из-за порога уверенности; повторения проверяются по правилам. Фазы учитываются с их собственной уверенностью, а среднеквадратичный провал энергии сохраняет ранний риск. Завершённые группы корневых ответов сохраняются при дедлайне.

Добавлены ограниченное разнообразие дебютов, сохранение альтернативных планов, восстановление истории из последовательных FEN, `save/load` партий, диагностический вывод энергии/уверенности. Исправлена видимость коэффициентов `W:*` для UCI-клиентов. Математические константы поля вычисляются один раз. Нет minimax, alpha-beta, нейросети или вызова Stockfish из движка.

## Воспроизводимые проверки

- 27 Rust-тестов прошли, включая альтернативный план, FEN-обновления, повторения, отмену, повреждённый журнал и воспроизводимое разнообразие.
- 8 UCI-тестов прошли: stop/EOF/isready, новые опции, соответствие bestmove и PV, история при FEN и Clear Hash, детерминированный анализ.
- Все встроенные проверки прошли, включая мат в один, жертву ферзя с матом в два, защиту от мата, доведение четырёх выигрышных позиций.
- Независимый oracle python-chess: 253 позиции, 246700 узлов perft(2); все легальные ходы и хэши совпали.
- Тактический набор: обе версии 6/6 на фиксированной длине 8 и при 250 мс; все 24 показанные линии каждой версии легальны. Медиана длины при 250 мс: 11.5 у 2.2 и 18.5 у 3.0. Установка более высокого предела не гарантирует достижение его за любой лимит времени.

## Матчи

Общие условия: один поток каждому движку, Hash 16 МиБ, Move Overhead 0, предел цепочки/глубины 64, разнообразие отключено для воспроизводимости, перестановка цветов. Победы определяются по правилам; оценки движков не используются для присуждения. JSON содержит SHA-256 бинарных файлов, параметры и конечные FEN, PGN содержит все ходы.

| Набор | Победы 3.0 | Поражения 3.0 | Ничьи |
|---|---:|---:|---:|
| Контроль против 2.2, 16 партий, 150 мс, параллельные серии | 4 | 6 | 6 |
| Последовательный контроль против 2.2, 16 партий, 250 мс | 7 | 7 | 2 |
| Полный Stockfish 19, начальная позиция, 4 партии, 150 мс | 0 | 4 | 0 |
| Полный Stockfish 19, **заранее выигрышные позиции для 3.0**, 8 партий, 150 мс | 8 | 0 | 0 |

Результаты настройки отличались: лучшая пробная серия дала 6 побед, 1 поражение и 1 ничью, но она использовалась для выбора коэффициентов и не является независимым подтверждением силы. Неудачные настройки и ранние контрольные серии сохранены в `reports/v3/experiments`.

**Рост Elo не подтверждён. На последовательной контрольной серии 250 мс — равный результат; на серии 150 мс новая версия набрала меньше очков. Побед над полным Stockfish с равной начальной позиции нет.** Победы из позиций с лишним ферзём/ладьёй проверяют доведение готового перевеса и не означают победу с равного старта. Прогноз матовой траектории не доказывает отсутствие других защит.

Первые серии запускались параллельно в среде с квотой 2 CPU, поэтому короткие временные лимиты шумны. Дополнительный последовательный матч при 250 мс выполнен без других локальных шахматных матчей/сборок: 7 побед, 7 поражений, 2 ничьи; `validation-250ms.json` и соответствующий PGN. Он не использовался для последующего изменения настроек. Числа Elo из этих коротких матчей не рассчитываются.

## Источники и запуск

Исходная версия сохранена в ветке `baseline-2.2`, коммит `ce4094fdac7d07f3d2c24afb667aadd3c3bb3e22`. Новая версия — `wave-engine-v3`. Старые отчёты находятся в `reports/baseline-2.2`, новые — `reports/v3`.

Stockfish 19 скачан из официального релиза https://github.com/official-stockfish/Stockfish/releases/tag/sf_19 и запущен локально с `Skill Level=20`, `UCI_LimitStrength=false`. Он используется только для тестов, в поставку WaveChess не включён.

```sh
python tests/arena.py --baseline /path/to/2.2 --revised /path/to/3.0 --opening-offset 8 --games 16 --movetime-ms 150 --output validation.json
python tests/arena.py --baseline /path/to/stockfish --revised /path/to/3.0 --suite start --games 4 --movetime-ms 150 --baseline-options '{"Skill Level":20,"UCI_LimitStrength":false}' --output sf-start.json
python tests/arena.py --baseline /path/to/stockfish --revised /path/to/3.0 --suite conversion --games 8 --movetime-ms 150 --baseline-options '{"Skill Level":20,"UCI_LimitStrength":false}' --output sf-conversion.json
```

Для матча с включённым разнообразием добавьте `--revised-options '{"Opening Variety":20,"Random Seed":42}'`. Для измерения силы нужен существенно больший независимый турнир при стабильном CPU и нескольких контролях времени.
