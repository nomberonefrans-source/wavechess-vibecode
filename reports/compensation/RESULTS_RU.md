# Компенсация после взятия

Базовая версия — `239a9b5`. Изменён расчёт первого хода каждой траектории из корневой позиции. Поправка действует в обычной игре и в UCI-анализе. В общий кэш локальных оценок попадают только обычные оценки, пригодные для повторного использования в глубине.

**Перенос угрозы.** Для выгодного взятия движок измеряет, насколько вырос доступный противнику поток материала на другой клетке после ухода защитника или вскрытия линии. Клетка самого взятия исключена: ответные взятия на ней уже учитывает исходная модель. Если взятие приносит как минимум стоимость коня, дополнительно проверяется возможность поставить мат следующим ходом. Расход материала оценивается по наиболее выгодному для соперника взятию с учётом этой компенсации. Оценка потока остаётся локальной эвристикой.

**Свобода защиты.** После корневого хода без шаха движок проверяет, есть ли конкретный мат в один ход, если соперник пропустит очередь. Затем на настоящей доске он проверяет этот же ход после каждого легального ответа. Для N ответов и D ответов, снимающих угрозу, прибавка составляет 50 · log₂((N+1)/(D+1)) сотых пешки, с потолком 200. Ответ, дающий ничью по счётчику полуходов или повторению, считается защитой. В UCI это позиционная оценка. Она не сообщает о форсированном мате.

Пример из WAC.001 при 512 узлах: белые перешли с Nh5 на эталонное Qg6. На fxg6 следует Nxg6#. Чёрные могут отказаться от взятия.

## Итоговая сборка

Проверка шахующих ходов использует предварительный геометрический фильтр. Для подтверждения мата всё равно проверяются легальность хода, шах и отсутствие легального ответа. При 512 узлах на всех 680 позициях исходная 4.0, предыдущая и итоговая сборки решили соответственно 70, 79 и 107. Подсчёт узлов отражает вызовы оседания поля. Новая версия выполняет дополнительные проверки внутри корневой оценки, поэтому результаты при равном времени измерялись отдельно.
